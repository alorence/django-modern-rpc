# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 2.1.x   | :white_check_mark: |
| 2.0.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| <= 1.0  | :x:                |

## Reporting a Vulnerability

If you believe you have found a security vulnerability in django-modern-rpc, please report it privately
using [GitHub Security Advisories](https://github.com/alorence/django-modern-rpc/security/advisories/new).

**Please do not open a public issue to report a security vulnerability.** Public disclosure before a fix
is available could put users of the library at risk.

Reports will be reviewed and handled as soon as possible, depending on the availability of the main
maintainer. Thank you for your patience and for responsibly disclosing any issue you may find.
